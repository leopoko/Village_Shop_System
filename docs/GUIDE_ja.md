# Village Shop System はじめてガイド

> English: [GUIDE.md](GUIDE.md)

最初のお店を作る手順と、「村人が取引してくれない」ときに確認することをまとめたガイドです。

**一番大事なこと:** このModでは、プレイヤーが村人に話しかけて取引するのではありません。**棚に商品を並べておくと、村人が自分で歩いてきて買っていきます**（または仕入れてくれます）。プレイヤーは待って、エメラルドを回収するだけです。

---

## 1. 3分で作る最初のお店

試すだけなら **売却棚1つ** で十分です。

1. **売却棚をクラフト**
   ```
   [木材]   [木材]       [木材]
   [本棚]   [エメラルド] [本棚]
   [木材]   [木材]       [木材]
   ```
2. **村の中の、村人が歩いて近づける地面に置く**（村人が棚から2ブロック程度まで近づける必要があります）
3. **開いて、村人が欲しがる物を入れる。** 棚の中のアイテムにカーソルを合わせ、`売却: ...` と価格が出れば売れます。取引できない旨が表示される物は売れません。
   最初は **パン・小麦・ニンジン・ジャガイモ・石炭・紙・鉄インゴット** などがおすすめです。
   棚の画面の **`?` ボタン** を押すと、売れるアイテムと価格の一覧が見られます。
4. **待つ。** **最大2分ほど何も起きないのは正常です**（[タイミング早見表](#timing)参照）。村人が来ると取引音が鳴って緑のパーティクルが出て、商品が右側のスロットのエメラルドに変わります。
5. **エメラルドを回収する。** 出力スロットから取り出すか、下にホッパーを置きます。

ここまでで基本はおしまいです。以下はすべて任意の発展要素です。

## 2. ブロック一覧

| ブロック | できること | レシピ |
|---|---|---|
| **売却棚** | 村人があなたの商品を**買い取り**、エメラルドを払います。左に商品18スロット、右にエメラルド9スロット。 | 木材×6、本棚×2、エメラルド |
| **売却棚（会計）** | 売却棚と同じ機能に加えて、**店グループ**に所属できます。エメラルドはグループのレジに送られます。この棚を使った村人は「買い物コース」を回ります（3章）。 | 売却棚のレシピの下段中央を金インゴットにしたもの |
| **購入棚** | プレイヤーが村人から**買う**ための棚。エメラルドを入れて欲しい物を設定すると、村人が仕入れて補充してくれます。 | 木材×6、チェスト×2、エメラルド |
| **レジ** | 同じ店グループの会計棚のエメラルドが集まります。プレイヤーは取り出しのみ可能です。 | 滑らかな石×8、エメラルド |
| **店舗設定棒** | 店グループ名・椅子・立ち位置を設定する道具。 | エメラルド／金インゴット／棒（縦一列） |

### ホッパー

- **売却棚:** 商品は**上面・側面**から搬入、エメラルドは**底面**から搬出
- **購入棚:** エメラルドは**上面・側面**から搬入、買った商品は**底面**から搬出
- **レジ:** エメラルドを**底面**から搬出のみ

### 購入棚の使い方

1. 左側のスロットにエメラルドを入れる
2. **欲しいアイテムを手に持って、金色に光るスロットをクリック**する（見本として登録されるだけで、アイテムは消費されません）
3. 見本スロットにカーソルを合わせると1個あたりの価格が見られます。村人がやってきて、エメラルドを使って出力スロットに補充します

購入価格は意図的に高め（デフォルトでバニラの5倍）です。**最低でも1個分のエメラルド**が入っていないと村人は来ません。

## 3. 本格的なお店を作る（店グループ）

**店グループ**は、複数の **売却棚（会計）** と1つ以上の **レジ** を共通の名前でまとめる仕組みです。グループ内の棚を1つ利用した村人は、

1. 同じグループの棚をさらに **1〜3個** 回り、
2. **レジ** に行って支払い（効果音とパーティクル）をして、
3. **椅子** に座るか **立ち位置** に立って、買った物を食べながら少し休み（設定してあれば）、
4. 帰っていき、クールダウン後にまた来ます。

### 手順

1. **売却棚（会計）を2つ以上** と **レジを1つ** 置く
2. すべてに **同じグループ名** を付ける。方法はどちらでもかまいません。
   - **一番簡単:** 会計棚・レジを **素手でスニーク＋右クリック** し、名前を入力して確定
   - **店舗設定棒を使う**（ブロックが多いとき便利）:
     1. 棒を持つとアクションバーに現在のモードが出ます。**スニーク＋右クリック** でモードを切り替え、**店グループ設定** にします
     2. **空中を右クリック** すると名前入力画面が開くので、グループ名を入力します。棒がその名前を覚えます
     3. 会計棚とレジを **右クリック** すると、名前が適用されます
3. （任意）**椅子と立ち位置**。グループ名を覚えた棒で、
   - **椅子設定** モードにして **階段ブロック**（座らせたい任意のブロック）を右クリック
   - **立ち位置設定** モードにしてブロックを右クリック。村人はそのブロックの **上** に立ちます
   - **削除** モードで椅子・立ち位置を右クリックすると解除
   棒を持っている間は、グループのブロックがパーティクルで表示されます（椅子は緑、立ち位置は白、棚はキラキラ、レジは緑と金）。
4. 棚に商品を入れて待ちます

> **注意:** v1.1 では、店舗設定棒で棚を右クリックしても棚の画面が開くだけで、グループ名を適用できない不具合がありました。**v1.2 で修正済み**です。v1.1 では素手でのスニーク＋右クリックを使ってください。

## 4. 困ったとき：「村人が取引してくれない」

上から順に確認してください。たいていは最初の3つのどれかです。

| 確認すること | 理由 |
|---|---|
| **2〜3分待ちましたか？** | ワールド読み込み直後、村人はそれぞれランダムに **最大2分** 待ってから買い物を始めます。買い物の後も **2〜3分** 待ちます。棚を探すのも **10秒に1回** です。 |
| **昼間ですか？** | **寝ている村人は買い物をしません。** デフォルトでは寝ている間はクールダウンも進みません。子どもの村人は買い物をしません。 |
| **ツールチップに価格が出ますか？** | 価格が付く物しか売れません。棚の中でカーソルを合わせるか、**`?`** で一覧を確認してください。他Modのアイテムは、設定で価格を追加しないと売れないことが多いです。 |
| **棚は近くにありますか？** | 村人は自分から **32ブロック以内**（設定で変更可）の棚しか探しません。 |
| **村人は棚まで歩いて行けますか？** | **30秒以内** に棚から2ブロック程度まで近づけないと、あきらめて帰ります。フェンスで囲う、周りにハーフブロックを置く、1マスの段差、近づけないカウンターの上に置く、などは避けてください。 |
| **エメラルド欄がいっぱいではありませんか？** | 出力スロットが満杯の売却棚は無視されます。空けるかホッパーを付けてください。会計棚の場合はレジの空きも数えます。 |
| **購入棚：エメラルドは足りていますか？** | 最低1個分の価格のエメラルド、見本アイテムの設定、出力スロットの空きが必要です。 |
| **来たのに一部しか買っていかない** | 正常です。村人には1回の来店ごとに **予算**（デフォルトで10〜30エメラルド）があります。大量の商品は何回かに分けて売れていきます。 |

それでも来ないときは、昼間に棚の近くで数分待ってみてください。**ベルの音と緑のパーティクル** が出たら **買い物ラッシュ** です。周りの村人のクールダウンがリセットされ、一斉に買い物に来ます。

## 5. 価格と設定

**Mod Menu**（Fabric）か **Mod一覧**（NeoForge）から設定画面を開くか、`config/village_shop_system.json` を直接編集します。

### 価格の決まり方

1. 設定ファイルの **カスタム価格** が最優先
2. **エンチャント本:** レベルとレア度から自動計算
3. **バニラの村人が扱うアイテム:** バニラの取引価格を使用
4. **食べ物:** 満腹度の回復量から自動計算
5. **ツール:** 耐久値と採掘速度から自動計算
6. **ポーション:** 効果と持続時間から自動計算

**売るとき** は **売却ペナルティ**（デフォルト −1 エメラルド）が引かれます。1エメラルドの物は、代わりに必要な個数が増えます。**買うとき** は **購入価格倍率**（デフォルト ×5）がかかります。

### 特定のアイテムの価格を変える

`config/village_shop_system.json` で、Modのアイテムも含めて好きな価格を付けられます。

```json
"customSellPrices": {
  "minecraft:cake": [1, 1],
  "minecraft:diamond": [8, 1],
  "farmersdelight:tomato": [1, 12]
},
"customBuyPrices": {
  "minecraft:name_tag": 20
},
"enchantedBookBuyPrices": {
  "minecraft:mending": 125
}
```

- `customSellPrices`: `"アイテムID": [エメラルド数, 個数]`。例えば `[1, 12]` はトマト12個で1エメラルドという意味です。
- `customBuyPrices`: `"アイテムID": 1個あたりのエメラルド数`（購入棚用）
- カスタム価格には売却ペナルティも購入倍率もかかりません。

### エメラルド以外の通貨を使う（v1.2以降）

**`currencyItem`** に任意のアイテムIDを指定します（他Modのコインなど）。

```json
"currencyItem": "examplemod:gold_coin"
```

棚とレジは、エメラルドの代わりにそのアイテムを1:1で支払い・受け取りします。**サーバーと全クライアントで同じ値にしてください。**

### その他の主な設定

| 設定 | デフォルト | 意味 |
|---|---|---|
| `villagerSearchRange` | 32 | 村人が棚を探す範囲（ブロック） |
| `villagerShoppingCooldownTicks` | 2400 | 買い物と買い物の間の基本待ち時間（20tick = 1秒） |
| `minShelvesToVisit` / `maxShelvesToVisit` | 1 / 3 | 店グループで追加で回る棚の数 |
| `villagerBudgetPerTrade` | 20 | 村人が1回の来店で使う平均エメラルド（50%〜150%） |
| `shoppingRushChance` | 0.005 | 買い物ラッシュが起きる確率 |
| `pauseCooldownWhileSleeping` | true | 寝ている間はクールダウンを進めない |

## よくある質問

**商店街を作らないとダメ？**
いいえ。村人の近くに売却棚が1つあれば動きます。店グループ・レジ・椅子は、お店を賑やかにするための要素です。

**価格を自分で決められる？**
はい。[特定のアイテムの価格を変える](#特定のアイテムの価格を変える)を見てください。

**他Modのコインを通貨にできる？**
v1.2 からできます。[エメラルド以外の通貨を使う](#エメラルド以外の通貨を使うv12以降)を見てください。

**村人はレベルアップする？**
はい。取引が成立するたびに村人に取引経験値が入り（設定で変更可）、職業レベルが上がります。

**家具Modの椅子は使える？**
椅子設定モードはどのブロックでも登録できるので、家具Modの椅子を座る場所にできます。座る高さはブロックの底から少し上です。

**MCA Reborn の村人で動く？**
未検証です。このModはバニラの村人（`Villager`）向けに作られています。他Modの村人で動くかどうかは、そのModの実装次第です。

**対応バージョンは？**
Minecraft 1.21.1（Fabric / NeoForge）。1.20.1 版（Fabric / Forge）を開発中です。

<a name="timing"></a>
### タイミング早見表
- ワールド読み込み後の最初の買い物: **0〜2分**（村人ごとにランダム）
- 買い物と買い物の間: **2〜3分**
- 棚の探索: **10秒ごと**、**32ブロック以内**
- **30秒** で棚に着けなければあきらめる
